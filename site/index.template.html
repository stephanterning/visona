macOS app · VST3 · AU · CLAP · Windows · Linux · Raspberry Pi

Locked to the beat

MIDI Clock sync with Start, Stop, Continue and Song Position Pointer. As a plugin it follows the DAW's transport directly. FREE mode runs at a manual BPM.

Sweep scope

Bar grid, stacked left and right lanes and a bright write head. Windows from a quarter bar to four bars, horizontal zoom and a measurement ruler.

Three waveform modes

STD, PRECISE and DJ, where colour follows frequency. Display gain up to 18 dB, with optional auto gain.

Latency you can see

Visona Sync puts a bar impulse on the plugin's sidechain, so Visona measures how late the audio arrives after plugins with latency, and draws it on the grid.

Everywhere you work

Standalone app on macOS, VST3, AU and CLAP plugins, Windows and Linux plugins, and a Raspberry Pi kiosk appliance for a dedicated screen in the studio.

Open source

Written in C++ with JUCE and released under the AGPL-3.0. Built and checked on GitHub Actions for every release.

Installing on macOS

Builds are not notarized yet. If Gatekeeper blocks the app, run xattr -cr /path/to/Visona.app. Plugin bundles go into ~/Library/Audio/Plug-Ins/VST3, Components or CLAP; see the manual.

Windows and Linux

VST3 and CLAP plugins for Windows x64 and Linux x86_64. Install folders are listed in the manual.

Raspberry Pi

Raspberry Pi OS 64-bit. See Pi setup and kiosk mode, or install over SSH with install-visona.sh.

Verify a download

Compare shasum -a 256 <file> with the table, or download the channel's SHA256SUMS next to the files and run shasum -a 256 -c SHA256SUMS --ignore-missing.
